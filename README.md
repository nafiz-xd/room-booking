# Room Booking 🏨

A demo **hotel / guest house room booking** app — pick dates, see live prices, book a room.

## 🔗 Live Demo
👉 https://nafiz-xd.github.io/room-booking/

## ✨ Smart Features
- **Date-based pricing** — choose check-in/check-out and every room shows the total for your exact stay (nights calculated automatically, invalid dates are fixed for you)
- **Filters** — by number of guests and room type (AC / Non-AC / Family / Suite), plus price & popularity sorting
- **Transparent totals** — nightly rate × nights + 5% service charge, itemised before you book
- **Booking flow** — name & phone form, instant confirmation with a booking ID
- **My Bookings** — your bookings are saved in the browser (localStorage) and can be cancelled anytime

## 🛠️ Tech
HTML • CSS • JavaScript • localStorage — single page, hosted on GitHub Pages. Demo only — no real reservations are made.
